## 🚀 Run Locally

### Prerequisites

- Node.js
- npm
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/mihreteabmelese-spec/Agoza-leathers.git
```

Navigate to the project:

```bash
cd Agoza-leathers
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
